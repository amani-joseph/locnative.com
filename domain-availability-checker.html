# Domain Category Root / Meaning Status Register on Cloudflare
How this works: Availability is checked via RDAP (Registration Data Access Protocol), the public IANA-standard registry lookup that replaced WHOIS. A 404 response means the domain is not currently registered and is likely available. A 200 means it is registered. This is the same data source Cloudflare's registrar queries.

Note: Available via RDAP ≠ guaranteed purchasable — some domains may be in the Cloudflare marketplace, premium-priced, or reserved. Always confirm on Cloudflare before committing. Checking ~90 domains takes about 15–30 seconds.
