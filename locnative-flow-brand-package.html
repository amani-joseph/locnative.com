04

Usage rules

Clearspace equals one grid-dot on all sides. Minimum size 24px digital / 8mm print (below which the fused-stroke fallback applies). And the non-negotiables:

DoUse the mark on void or panel surfaces at full opacity structure.
Don't rotateThe grid is the geometry. Never tilt, skew, or flip the mark.
Don't recolourOnly the three sanctioned colourways. No off-palette substitutions.
Don't stretchAlways scale proportionally. The dot grid must stay square.

08

Motion

The pulse follows the stroke order. The L's dots brighten top → bottom → right; a beat later the N answers bottom → top → diagonal → up — exactly the direction each letter is written. Cycle length 3.2s, ease-in-out, staggered 250ms per dot. Used for loading states, the docs splash, and the animated favicon. Respects prefers-reduced-motion — static final frame when set.
